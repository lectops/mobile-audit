# Local model provenance

Primary: existing community quantization at https://huggingface.co/mradermacher/Huihui-Qwen3-Coder-30B-A3B-Instruct-abliterated-i1-GGUF, based on huihui-ai/Huihui-Qwen3-Coder-30B-A3B-Instruct-abliterated, derived from Qwen/Qwen3-Coder-30B-A3B-Instruct. The installed GGUF's metadata states qwen3moe architecture, Apache-2.0 license, Q4_K_S quantization and 262144 context limit. This is an altered community derivative, reused explicitly with a 16384-token limit. Inference was tested with llama.cpp 0.7.0 on Metal and no network access. No Qwen weight download occurred.

Reviewer: official Cisco Foundation AI repository https://huggingface.co/fdtn-ai/Foundation-Sec-8B-Reasoning at revision `63c930c82d7646226d33502bec5870019738400e`. Model card identifies Meta Llama 3.1 8B backbone, with 32768-token training sequences; config declares 131072 maximum positions. Conservative configured context is 16384. NOTICE applies Meta's Llama 3.1 Community License to the base and Apache-2.0 to Cisco changes; this is not an entirely Apache-only model. Local copies of NOTICE and license references are in models/foundation-official.

Original safetensors are downloaded from the official revision after user approval. Conversion uses a locally checked-out llama.cpp converter without trust-remote-code. An F16 intermediate is quantized locally with llama-quantize Q4_K_M. `models/provenance.json` (sanitized reference: `docs/model-weights.json`) records original and resulting SHA-256 digests, byte sizes, official revision and converter revision. `models/conversion.log` records conversion diagnostics. No third-party Foundation-Sec quantization is substituted. Reviewer enablement follows an actual inference test.

The inference runtime is direct `llama-completion`, not the installed llama-cli frontend that attempts to allocate a local server port. Each subprocess is network denied, receives a bounded prompt from a private temporary file, and exits before the next model is loaded. No Ollama changes are necessary. The process does not accept any HTTP endpoint or download URL from the repository or model.

Deployment validation completed: all four official shard SHA-256 values matched the pinned official repository metadata. Q4_K_M file size: 4,920,851,232 bytes. Foundation-Sec responded under OS network denial; runtime diagnostics confirmed 33/33 layers offloaded to Apple M4 Max GPU. The reviewer is enabled in the private local configuration once its weights are configured. Task-created F16 intermediate and abandoned partial downloads were removed after validation; original Cisco weights and Q4 output are retained.
